A small personal website: a home page, a projects page and a dark mode toggle.
Plain HTML and CSS with a few lines of JavaScript. No frameworks, no build step.

## Run it locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then go to <http://localhost:8080>.

## Project structure

```
.
├── index.html          # home page
├── projects.html       # projects page
├── css/style.css       # all styles, light and dark theme
├── js/main.js          # dark mode toggle
└── assets/favicon.svg
```
