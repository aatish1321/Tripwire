# Contributing

Thanks for wanting to help! This is a small personal site, so contributions are simple:

1. **Found a bug or a typo?** Open an issue with the *Bug report* template.
2. **Have an idea?** Open an issue with the *Feature request* template first, so we can talk about it.
3. **Pull requests** are welcome for fixes. Keep them small and describe what changed.

There's no build step: edit the HTML/CSS and open `index.html` in a browser to check your change.
